# 教學規則（已確認）

## 目標與排程
- 學習路線 A2 → B1 → B2 → C1；C1 為長期進階目標，不代表目前能力。
- 每天 08:00 Europe/Amsterdam 提供 10–15 分鐘課程；僅於臨時要求時縮短至 8 分鐘。
- 每週另設獨立複習與測驗，不取代每日課程。
- 前一課未見答案或明確學習確認，下一次重複相同主題、核心句型及大致相同詞彙，標示「重溫／補課」，不擅自認定使用者未閱讀。
- 有完成練習或明確確認後才推進；輸入中斷不得直接視為能力錯誤。

## 每課設計
- 約 3 分鐘無提示舊詞回憶；5–6 分鐘核心句型及約 8–12 例句、4–6 句對話；3–5 分鐘練習。
- 新課一般新增 8–12 個高頻詞／搭配，可按表現調整至 5–15；補課不新增。
- 詞彙需有 NL／EN／繁體中文，名詞冠詞、必要動詞形式及常用搭配；兼顧生活、跨行業工作、行政、教育及求職，酒店僅偶爾出現。
- 同一核心句型連續 2–3 課練習，使用不同人稱、動詞與日常場景交叉替換。
- 每課約 10–12 個短小題目，其中至少 6–8 題為完整荷蘭語自主造句；口語優先，但不可取消書寫。
- 正式題目主要呈現 EN／繁體中文，不預先提供答案骨架；可選顯示少量**無序**荷蘭語詞庫。
- 先示範新動詞的實際原形、必要現在式及過去分詞，再測試；已懂概念不代表熟悉每個動詞形式。
- 批改重視可理解性、自然口語、詞序與變位；拼字及疑似輸入遺漏從輕。

## 重要文法主題
- de/het 名詞；指示詞 die/dat；代詞 het/die/dat；關係代詞 die/dat；無先行詞的 wat。
- 主句 V2、時間前置倒裝、maar 後新主句、omdat/dat/als 從句、間接問句 waar/hoe/waar ... naartoe。
- 頻率副詞 meestal/soms/altijd/nooit/vaak，時間副詞 vroeg/laat；niet 與 nooit 區別。
- Modal + infinitive、hoeven niet te、laten、om ... te、bellen + iemand、可分動詞與過去分詞。
- 先用短句解釋，再拆主語／動詞／賓語／時間／否定，對比複合句，避免過度文法術語。

## 詞彙進度原則
- 1,000 高頻詞是初期里程碑，不等於 B2/C1 所需詞量。
- 「已介紹」「辨認」「回憶正確」「自由運用」分別記錄；沒有可核實紀錄時不得填入累計掌握數。
- 舊詞間隔複習目標 3／7／14／30 日；僅按實際可見紀錄判斷是否完成。
