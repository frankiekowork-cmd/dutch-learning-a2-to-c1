# Day 32 批改重點

- 1：正確，de winkel die。
- 2：`pakke` 拼字；原題 that parcel 應為 `dat pakket`，原句 `het pakket` 文法可成立但指示意思不同。
- 3：正確，het formulier dat。
- 4：`je fiets staat`（單數），非 staan。
- 5：正確，`Morgen zal ik ... controleren`。
- 6：`afspraak` 拼字；`soms` 句末可用，句中更常見。
- 7：`die ... controleert`，非 controleren。
- 8：`Omdat ik mijn fiets niet kan vinden, moet ik lopen`；主要是 niet 位置。
- 9：`die je stelt`，但 `stellen/stelt` 未先教；不得作已教動詞變位扣分。
- 10：`ben` 拼字；maar 後 V2 正確。
- 11：`Wat ik nodig heb, ligt naast de ingang` 更自然；`is naast` 不必一律判為文法錯誤。
- 12：正確，`waar je naartoe wilt`。

拼字及可能的輸入遺漏從輕；不要以簡單題成功推論複合句全面掌握。
