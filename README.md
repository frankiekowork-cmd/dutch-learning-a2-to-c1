# Dutch Learning | A2 → B1 → B2 → C1

以繁體書面中文管理的荷蘭語課程資料庫與離線互動網站。

## 功能
- 每日課程與三語詞彙（荷蘭語／英語／繁體中文）
- 自由造句、可選的打亂詞庫、瀏覽器本機儲存答案
- 可匯出答案 JSON，避免僅依賴對話輸入框
- 已核實的學習進度與來源狀態，區分「已介紹」「已作答」「已掌握」
- GitHub Pages 可直接發布的靜態網站，無需建置或付費服務

## 使用方式
1. 將整個資料夾上傳至 GitHub 儲存庫（建議先設為 Private）。
2. 在本機直接開啟 `web/index.html`，或透過簡易 HTTP 伺服器執行 `python -m http.server 8000`，前往 `http://localhost:8000/web/`。
3. 若要發布網站，將 GitHub Pages 的 Source 設為 **GitHub Actions**；推送到 `main` 後工作流程會部署 `web/`。
4. 編輯 `web/content.js` 及 `lessons/` 新增經核實的課程。`data/` 為可機器讀取的課程紀錄。

> GitHub Pages 發布後，網站網址可能公開；**Private 儲存庫不等於 Private 網站**。切勿將私人學習答案、身份資料或帳戶資訊直接提交到公開網站。瀏覽器本機儲存不會自動同步至 GitHub。
